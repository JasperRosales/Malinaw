# User Guide

## 1. Add a document

Pick a source tab:

- **Text** – paste or type text, or load the built-in sample.
- **Photo** – choose, drop, or take a photo. Pick the OCR language
  (English, Filipino, or both) and keep **Enhance** on for faint prints.
  Press **Read photo**.
- **PDF** – choose or drop a PDF. Text-based pages are read directly.
  With **OCR scanned pages** on, image-only pages are scanned too.

When text is extracted, the workspace opens.

## 2. Simplify

Press **Simplify** to rewrite the text in plain language.

- With a Gemini API key set, AI rewrites the text.
- Without one, a built-in word/phrase simplifier runs offline. Changed
  words are highlighted (toggle in settings).

A readability score (Flesch Reading Ease) compares original and simplified.

## 3. Listen

Use the listen buttons on any pane (original, simplified, translation).
The player bar lets you play/pause, stop, change speed, and pick a voice.
The word being read is highlighted if **Highlight while reading** is on.

## 4. Translate

Choose source and target language (English, Filipino, Spanish, Cebuano)
and whether to translate the simplified or original text.

## 5. Explain a word

Tap a word, or select text and press **Explain**. You get a simple
definition, dictionary meaning, a simpler replacement word, and a
translation when available.

## 6. Ask a question

Type a question about the document. With AI, you get a short answer based
only on the document. Without AI, the most relevant sentences are shown.

## 7. Save or share

Copy the text, download it as `.txt`, or (on Android) save/share it.

## Accessibility settings

Open **Settings** to change:

- Theme: Light, Cream, Dark, High contrast
- Font size, line height, letter spacing
- Reading speed
- Legible font, highlight changes, highlight while reading, reduce motion

Settings are saved on the device.

## Keyboard shortcuts

| Keys | Action |
| --- | --- |
| `Alt+1` | Go to the Text tab and focus the input |
| `Alt+2` | Play / pause reading |
| `Esc` | Close the settings panel |
