# Malinaw Documentation

Malinaw ("clear" in Filipino) is an accessible reading assistant. It turns
photos, PDFs, and difficult text into plain, listenable, translated content
for people with low vision, reading difficulties, or limited literacy.

It ships as a Progressive Web App (PWA) and as an Android app via Capacitor.
